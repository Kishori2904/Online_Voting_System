# Online_Voting_System
A secure and efficient web-based voting platform built using PHP, MySQL, HTML, CSS, and JavaScript. It enables users to register, log in, and cast their votes online, ensuring transparency and one-person-one-vote authentication. Admins can manage candidates, monitor voting activities, and view live results through a dedicated dashboard.

🚀 Features
🧑‍💻 User Authentication – Register, log in, and vote securely
🧾 Admin Dashboard – Manage users and candidates easily
🗳️ Vote Once System – Each user can vote only once
📊 Live Results Display – Instant and accurate result computation
🧠 Database Integration – Data stored securely in MySQL
📱 Responsive Interface – Works on all devices
🧰 Tech Stack
Category	Technologies
Frontend	HTML, CSS, JavaScript
Backend	PHP
Database	MySQL (via XAMPP)
Server	Apache (XAMPP)
⚙️ Installation Guide
Install XAMPP from https://www.apachefriends.org
Copy this project folder to
C:\xampp\htdocs\Online_Voting_System
